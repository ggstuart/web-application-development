In this module we will be using JavaScript to build an HTTP server.
This unit introduces the language and gets us started with a basic web server.

<!--more-->

> JavaScript is known as the programming language of the web because it is available as a scripting language in most browsers.
If you are interested in using JavaScript in the browser then you can choose the optional *advanced web development* module in the final year.
This module is good preparation for that.
