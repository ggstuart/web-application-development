> Note that HTML does not include any information about *how* to format **content**.

<h2>Example HTML</h2>
<p>
    This content is <em>marked up</em>
    using <strong>HTML</strong>.
    The code indicates that the first line is a level 2 heading.
    The rest of the text should be combined into one paragraph. 
    Emphasis has been added to a few of the words using <code>&lt;em&gt;</code>, <code>&lt;strong&gt;</code> and <code>&lt;code&gt;</code> tags.
</p>

```html {class=large}
<h2>Example HTML</h2>
<p>
    This content is <em>marked up</em>
    using <strong>HTML</strong>.
    The code indicates that the first line is a level 2 heading.
    The rest of the text should be combined into one paragraph. 
    Emphasis has been added to a few of the words using
    <code>&lt;em&gt;</code>, 
    <code>&lt;strong&gt;</code> and 
    <code>&lt;code&gt;</code> tags.
</p>

```
> It simply indicates what *kind* of **content** the various parts of the document are.
